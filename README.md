# SealOS

This is my very own Seal-Themed OS. I just really love seals and I wanted to make an OS about them lol.

## What does it have?
- **Introduction:** A very simple app to introduce you to the OS and me!<br>
- **Seal Clicker:** A very cool app to spend 10-20 minutes which is very similar to Cookie Clicker, but with Seals, I think you get the idea haha.<br>
- **SealTok:** A doomscrolling app to just watch seals, very entertaining, and brain rotting I guess.<br>

## Built with:
- **HTML**
- **CSS**
- **JavaScript**

## How to run locally:
- Clone the repository: ```https://github.com/IndieSeal/SealWebOS.git```
- Open `index.html`
- Enjoy SealOS!
